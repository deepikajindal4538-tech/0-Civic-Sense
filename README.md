# Civic Sense

Civic Sense is a civic issue reporting site with a React/Vite frontend and an Express backend.

## Requirements

- Node.js and npm

## Install

From the project root, install the dependencies for the root scripts, backend, and frontend:

```bash
npm install
```

## Run the site

From the project root, start the frontend and backend together:

```bash
npm start
```

Open the frontend at [http://localhost:5173](http://localhost:5173). The backend API runs at [http://localhost:5501](http://localhost:5501).

Leave the terminal running while using the site. Press `Ctrl+C` to stop both services.

### Run the services separately

If you prefer separate terminals, run these commands from the project root:

```bash
npm run start:backend
```

```bash
npm run start:frontend
```
